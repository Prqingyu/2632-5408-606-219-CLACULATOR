# 2632？ · 任意数构造器

> 仓库：https://github.com/Prqingyu/2632-5408-606-219-CLACULATOR

用给定的 8 个数字构造任意目标数，带图形界面。

**给定数字：`26 / 32 / 219 / 5408 / 606 / 326 / 2632 / 3226`**

## 规则（整串保序）

- 用到的给定数字必须**整串、按原顺序、相邻**地出现在式子里，只能插入运算符和小数点：
  - 例：`32 → 3+2` ✓，`5408 → 5.4+0.8` ✓，`219 → 2×19` ✓，`2632 → 26+32` ✓
  - 不能只取 `5408` 的 5 和 8（跳数字），也不能把 `219` 写成 `9…1`（倒序）
- 可以只用一部分给定数字；数字之间的先后不限
- 运算符：+ − × ÷、括号；可选幂 / 阶乘 / 平方根
- 常规规则搜不到时，用「对数 + 开方」的通用公式兜底（作弊模式，不遵守保序规则）

## 快速开始

双击 **`打开计算器.bat`** 或 **`index.html`**（纯静态，无需服务器、无需联网）。

```bash
npm start          # 可选：http://127.0.0.1:2632 本地预览
npm test           # 引擎测试
npm run screenshot # 可选：Edge 无头界面冒烟测试 + 截图
```

- 输入任意整数 / 小数 / 分数（如 `2026`、`3.14`、`1/3`、`-22`）
- 点 **开始构造**（或 Enter）；**换一个**（Tab）切换其它构造方式
- **🎲 随机数字** 随机生成一个目标（整数 / 小数 / 分数）
- **加强搜索** 用更久时间尝试更复杂的构造
- 顶部一排小圆点是当前可用的 8 个给定数字

## 实现原理

> 详见 **[ALGORITHM.md](ALGORITHM.md)**（简单版算法说明：保序表达式库、逆运算搜索、精确校验、对数兜底）。

1. **保序表达式库（bundle）**：对每个给定数字，枚举所有「切分方案 + 数字块小数点 + 相邻块运算」，得到「整串用完、顺序不变」的值集合。
2. **搜索**：1 个数字查表；2 个数字目标导向枚举；3 个数字按代价选「单数 × 双数」拆分、限时预算内枚举；更大组合留给兜底。
3. **双重校验**：BigInt 精确分数复核 + 整串保序校验（每个给定数字是否整串按序连续出现），双通过才展示。
4. **对数兜底**：任意整数 `n = −log₂(log₂(√(√(…√2…))))`（n 层根号，三个 2 来自 26/32/219）；任意分数用第二组种子（26 的 6 与 606 拆成 6|06）构造。兜底不遵守保序规则，界面会标「作弊」。

## 已知限制

- 严格保序规则下，部分大整数 / 复杂小数可能搜不到常规式子，会自动使用对数兜底（界面有标注）。
- 「任意实数」不可能精确构造（表达式只有可数个）；整数 / 有限小数 / 分数在允许对数时可以精确构造。
